🎬 Netflix Clone (ReactJS)
A sleek Netflix UI clone built using ReactJS and integrated with the TMDB (The Movie Database) API to display real movie data. This project replicates the look and feel of Netflix, including a dynamic banner, rows of categorized movies, and trailer previews.

🌟 Features
Fully responsive and modern Netflix-style UI

Fetches real-time movie data from TMDB API

Horizontal scrollable movie rows by category

Dynamic banner with featured movie

Trailer popup using YouTube embeds

Clean code structure using reusable components

🛠️ Tech Stack
ReactJS

Axios for API requests

TMDB API

CSS Modules

📁 Getting Started
Clone the repo
git clone https://github.com/rhtmishra/Netflix-Using-ReactJs.git

Install dependencies
npm install

Start the development server
npm start
